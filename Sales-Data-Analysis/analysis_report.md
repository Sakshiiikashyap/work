# Sales Data Analysis Report

## Objective

Analyze sales data using Python and Pandas.

---

## Dataset

Columns:

- Date
- Product
- Quantity
- Price
- Customer_ID
- Region
- Total_Sales

---

## Data Cleaning

- Checked missing values
- Filled missing numeric values using median
- Filled missing text values using "Unknown"
- Removed duplicate rows

---

## Metrics Calculated

- Total Revenue
- Total Quantity Sold
- Average Sale
- Highest Sale
- Lowest Sale
- Best Selling Product
- Revenue by Region

---

## Insights

- Laptop generated the highest revenue.
- North region contributed the most sales.
- Average transaction value is high compared to other products.
- No missing values remained after cleaning.

---

## Conclusion

The sales dataset was successfully analyzed using Pandas. Multiple business metrics were calculated to understand revenue, product performance, and regional sales distribution.
